# payloads/config — config templates

Symbolic templates for the per-run configs generated by
`../packaging/make_config.ps1`:

| File | Used by |
|---|---|
| `c0015.example.ini` | base `[lab]`/`[bootstrap]`/`[c2sim]`/`[beacon]` keys (HTA paths, C2 URL, loop timings) |
| (phase7) `config-phase7.ini` | elevated/second-session beacon + DLL surrogate (`[beacon] beacon_cmd`, marker names) |

No secrets: session token values are runtime-generated; credentials never appear in
these files or in logs. Per-run concrete copies live in gitignored `stage/`.
